# תיקיית העלאת תמונות — פרויקט יום הולדת 70 לתמי שפר
# Drop-Folder: Tamar "Tami" Sheaffer 70th-Birthday Celebration Project

ברוכים הבאים לתיקיית שיתוף התמונות והמסמכים עבור פרויקט יום הולדת 70 של תמר (תמי) שפר!  
תיקייה זו מיועדת עבור בני המשפחה לאיסוף, שימור וקטלוג של תמונות משפחתיות, סריקות היסטוריות, צילומי אמנות ותיעוד מתערוכות.

Welcome to the central media drop-folder for Tamar "Tami" Sheaffer's 70th-birthday virtual album and spatial archive!

---

## 1. כיצד להוסיף תמונות? (How to Add Photos)

פשוט גררו תמונות ישירות לתוך תיקייה זו (`drop_folder/`) או לתוך תת-התיקייה `drop_folder/incoming/`.

You can simply drag and drop images directly into `drop_folder/` or `drop_folder/incoming/`.

### פורמטים נתמכים (Supported Formats):
- **תמונות רגילות:** `.jpg`, `.jpeg`, `.png`, `.webp`
- **סריקות ואנימציות:** `.tif`, `.tiff`, `.gif`, `.bmp`
- **הערה לגבי iPhone/HEIC:** מומלץ לייצא תמונות מ-iPhone כ-JPEG (בהגדרות השיתוף: "Most Compatible" / "תואם ביותר").

## 2. הוראות ייצוא ממקורות נפוצים (Exporting from Common Sources)

### א. ייצוא מ-Google Photos (Google Photos Export)
1. **תמונה בודדת או אלבום:** היכנסו לאלבום ב-Google Photos, בחרו את התמונות, לחצו על שלוש הנקודות ובחרו **Download** (הורד).
2. **ייצוא מלא (Google Takeout):** אם הורדתם אלבום מלא דרך Google Takeout, תראו לצד כל תמונה קובץ נוסף המסתיים ב-`.json` (למשל `IMG_1234.jpg.json`). **השאירו קבצים אלו לצד התמונות!** כלי הקליטה קורא את קובצי ה-JSON באופן אוטומטי ומחלץ מהם את תאריך הצילום, המיקום והתיאור.

### ב. ייצוא מ-WhatsApp (קבוצת משפחת שפר)
1. בטלפון או ב-WhatsApp Web/Desktop, פתחו את השיחה של קבוצת **שפר**.
2. היכנסו לפרטי הקבוצה > **מדיה, קישורים ומסמכים (Media, Links & Docs)**.
3. סמנו את התמונות הרלוונטיות, לחצו על כפתור השיתוף ושמרו אותן בתיקייה זו.

### ג. סריקות של תמונות היסטוריות (סבא מיכאל, סבתא אהובה, הרצליה, חיפה)
- מומלץ לסרוק ברזולוציה של לפחות 300 DPI.
- כלי הקליטה מסנן באופן אוטומטי צלמיות ואייקונים קטנים (פחות מ-150x150 פיקסלים) כדי לשמור על איכות הארכיון.

## 3. הוספת מידע ותגיות (Optional Sidecar Metadata)

רוצים להוסיף מידע על התמונה (מי מופיע בה, היכן צולמה ובאיזו שנה)?  
באפשרותכם ליצור קובץ טקסט עם סיומת `.json` באותו שם של התמונה (למשל `herzliya_yard_1965.jpg.json`):

```json
{
  "title": "בחצר הבית בהרצליה",
  "caption": "תמי בחצר בית הוריה אהובה ומיכאל לצד עצי הפרי",
  "date_or_era": "1965",
  "people": ["תמר שפר", "אהובה שפר", "מיכאל שפר"],
  "places": ["הרצליה - בית הילדות והחצר"],
  "art_themes": ["חצר ועצים", "ילדות"]
}
```

## 4. הרצת כלי הקליטה (Running the Ingestion Pipeline)

לאחר הוספת התמונות לתיקייה, יש לפתוח את הטרמינל בתיקיית הפרויקט ולהריץ:

### א. תצוגה מקדימה ללא שינוי (Dry Run):
בודק את תקינות התמונות, מוודא שאינן פגומות, מחשב חתימות SHA-256 ומציג בדיוק מה ייקלט מבלי לשנות את הקטלוג:
```bash
python3 tools/ingest.py --dry-run
```

### ב. קליטה מלאה לקטלוג (Live Ingestion):
מעתיק את התמונות לספריית המדיה, מונע כפילויות, ומעדכן אוטומטית את קובצי הקטלוג (`catalog.json`, `catalog.csv`, `catalog.sqlite`, ו-`catalog/index.html`):
```bash
python3 tools/ingest.py
```

### ג. קליטה עם תיוג קבוצתי מהיר (Batch Tagging):
```bash
python3 tools/ingest.py --people "תמר שפר, גדי שפר" --places "חיפה - גרינבוים 80 (דניה והסטודיו)" --date-or-era "2018"
```
